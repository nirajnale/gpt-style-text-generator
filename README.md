# 🤖 GPT-style Text Generator

A deep learning NLP project implementing a **Decoder-Only Transformer Architecture** for autoregressive text generation using **TensorFlow/Keras**.

This project demonstrates the core concepts behind GPT-style language models including:

✅ Tokenization & Padding  
✅ Token + Positional Embeddings  
✅ Masked Self Attention  
✅ Decoder-Only Transformer Architecture  
✅ Feed Forward Networks  
✅ Next Token Prediction  
✅ Autoregressive Text Generation  

---

# 🧠 Model Architecture

The project uses a **Decoder-Only Transformer** consisting of:

- Token Embedding
- Positional Encoding
- Masked Multi-Head Self Attention
- Feed Forward Network
- Add & Layer Normalization
- Dense + Softmax Output Layer

The model predicts text sequentially one token at a time.
